# Download speed

Консольный замер скорости загрузки: Python 3.10+, только стандартная библиотека.

## Запуск

```sh
python3 speed.py https://example.com/large-image.jpg
python3 speed.py https://example.com/large-image.jpg --timeout 15
```

Замените пример адресом настоящего файла. Скрипт делает **ровно 10 GET-запросов последовательно**, каждый раз читает ответ до конца, затем начинает следующий запрос. Файл не сохраняется на диск: данные читаются блоками по 64 КиБ.

## Результат и единицы

Скрипт выводит количество запросов, суммарные байты, общее и среднее время запроса, скорость в **МиБ/с (MiB/s)** и **Мбит/с (Mbit/s)**.

- Среднее время = сумма длительностей 10 запросов / 10.
- Скорость = общий объём полученных тел ответов / сумма длительностей запросов.
- 1 МиБ = 1 048 576 байт; 1 Мбит = 1 000 000 бит; 1 байт = 8 бит.

Таймер `perf_counter()` охватывает открытие соединения, ожидание заголовков и чтение полного тела. Поэтому это эффективная скорость получения выбранного ресурса, включая задержки HTTP/DNS/TLS, а не гарантированная пропускная способность интернет-канала. Заголовки HTTP в объём не входят. Запрашивается ответ без сжатия и повторного использования кэша; сервер может игнорировать эти заголовки. Редиректы обрабатывает `urllib`.

При ошибке HTTP, сети или неполном ответе выполнение прекращается с кодом 1; неполный замер не выдаётся за результат десяти запросов. Некорректные параметры дают код 2. `--timeout` задаёт тайм-аут операций сокета, а не максимальную длительность всего замера. Автоматических повторов нет.

## Проверка

```sh
python3 -m unittest -v
```

Тесты запускают локальный HTTP-сервер: проверяют 10 последовательных загрузок, полный объём, учёт задержки до конца ответа, формулы, обработку HTTP 503 и неверных параметров. Внешний интернет для тестов не нужен.

## Как устроен код

`measure()` в цикле открывает URL и суммирует прочитанные байты и время. Неизменяемый `Result` вычисляет среднее и скорость. `main()` разбирает параметры, обрабатывает ошибки и печатает результат.

## Использование ИИ

Код, тесты и README подготовлены с помощью Codex. Решение проверено локально тестами с HTTP-сервером. Коммерческие проекты, личные данные и ключи доступа в репозиторий не включены.

Дальше можно добавить JSON-вывод для автоматизации, медиану и диапазон времени, а также отдельный режим прогретого соединения для сравнения влияния установления соединения. Параллельные запросы изменили бы методику, поэтому здесь они не используются.
